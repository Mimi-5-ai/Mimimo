2) خلاصة قواعد الفصول (11 و 12 و 13 و 14) في نقاط سريعة حاسمة:
• قاعدة Like vs Would like (فصل 11):
  - I like = I love (بشكل عام) ← في تمارين السلايد بدون 'd نختار بعدها الفعل بـ -ing (going / setting)، وسؤالها Do you like...? → Yes, I do / No, I don't.
  - I would like (I'd like) = I want (أكثر أدباً more polite) ← يأتي بعدها اسم أو to + infinitive (to visit / to live / to watch)، وممنوع يأتي بعدها -ing! وسؤالها Would you like...? → Yes, please / No, thank you.
• قاعدة Conditional with would (فصل 11):
  - مع الفعل الماضي (If + Past: went / got / were / won / rained / didn't have) ← نختار في الشق الثاني would / wouldn't + فعل مجرد.
  - مع المضارع البسيط (If + Present: comes / rains) ← نختار will ('ll) + فعل مجرد.
• قاعدة المبني للمجهول Passive Voice (فصل 12):
  - نبدأ بالمفعول به (Object): في المضارع نضع (is / are + التصريف الثالث V3)، وفي الماضي (مع yesterday / ago / in 1941) نضع (was / were + التصريف الثالث V3).
  - أهم التصاريف الثالثة في السلايد: break → broken | eat → eaten | speak → spoken | write → written | find → found | sell → sold | give → given | put → put | show → shown | know → known.
• قاعدة المضارع التام البسيط مقابل المستمر (فصل 13):
  - المضارع التام المستمر (have/has + been + verb-ing): للحدث غير المنتهي (unfinished) مع مدة زمنية: نختار How long للسؤال، و since قبل جملة بداية الحدث (since I come to Jeddah / since he came to Abha)، و for قبل المدة المعدودة (for two years / for about three weeks / for more than two hours).
  - المضارع التام البسيط (have/has + V3): للحدث المكتمل (finished / result) أو عند وجود عدد/كمية (16 books / 10 messages / hundreds of jobs → have applied) أو مع الأفعال الجامدة التي لا تقبل ing مثل الفعل (want → have wanted).
• قاعدة الماضي التام وأزمنة السرد Past Perfect & Narrative Tenses (فصل 14):
  - الماضي التام (had + V3): هو "ماضي الماضي" (حدث وقع واكتمل قبل حدث ماضٍ آخر مع before / when / because، مثل: had read / had owned / had saved / had already started / had bought).
  - الماضي المستمر (was/were + ing): حدث كان مستمراً في الخلفية عندما قطعه حدث ماضٍ بسيط (When he was checking his email / I was washing the dishes when I cut my finger).
