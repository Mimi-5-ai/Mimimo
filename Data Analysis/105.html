5 قواعد ذهبية للتمييز في الاختبار

1. Ridge مقابل Lasso

كلاهما يعالج التعددية الخطية (Multicollinearity) بإضافة معامل تنظيم λ، لكن Ridge يجمع مربعات المعاملات ويقلصها دون تصفيرها، بينما Lasso يجمع القيم المطلقة فيصفّر المعاملات غير المؤثرة ويقوم باختيار السمات تلقائياً.

2. اختيار السمات مقابل تقليصها (Filter vs PCA)

اختيار السمات (Filter) يحذف سمات بعينها ويبقي أخرى أصلية (مثل الارتباط Pearson)، بينما تقليص السمات (PCA / SVD) يدمج السمات معاً لتوليد عدد أقل من السمات الجديدة المدمجة مع حفظ غالبية التباين.

3. K-Means مقابل DBSCAN

K-Means تتطلب تحديد K مسبقاً (عبر Elbow / WCSS) وتفشل مع الأشكال غير الخطية وتتاثر بالقيم المتطرفة؛ أما DBSCAN فتعتمد على الكثافة (eps, minPts) وتكتشف الأشكال غير الخطية وتعزل القيم المتطرفة كضجيج.

4. Linear مقابل Logistic Regression

الأول للتنبؤ بقيم عددية مستمرة؛ والثاني رغم كلمة Regression هو نموذج تصنيف ثنائي يمرر الناتج الخطي عبر دالة Sigmoid لإخراج احتمال بين 0 و1 (عتبة 0.5).

5. Loss Function مقابل Gradient Descent

Loss Function (MSE) هي المقياس الذي يحسب معدل الخطأ؛ بينما Gradient Descent هي آلية البحث الموجّه التي تعدّل المعاملات θ لتقليل ذلك الخطأ عبر المشتقات.
