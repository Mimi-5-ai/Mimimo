UNIT 01 • FEATURE ENCODING TECHNIQUES

الوحدة الأولى: تقنيات ترميز السمات

تحويل البيانات النصية والفئوية إلى تمثيلات رقمية أو ثنائية تفهمها خوارزميات التحليل الإحصائي والتعلم الآلي دون فقدان المعنى أو فرض علاقات ترتيبية خاطئة.

1.1 مفهوم ترميز السمات وأهميته في تحليل البيانات

في سياق تحليل البيانات، يشير ترميز السمات (Feature Encoding) إلى عملية تحويل البيانات من صيغة معينة (مثل النصوص أو الفئات الاسمية والترتيبية) إلى مجموعة من القيم المعرفية أو الرموز الرقمية التي يمكن استخدامها في عمليات التحليل الإحصائي والتعلم الآلي — مثل تحويل البيانات النصية إلى أرقام أو تحويل البيانات الفئوية إلى متغيرات ثنائية.

1. تقليل الحجم والتعقيد

يساعد ترميز السمات في تقليل حجم البيانات وتبسيطها، مما يجعل عمليات التحليل أسرع وأكثر فعالية.

2. تحسين الأداء

يؤدي إلى تحسين أداء نماذج التحليل الإحصائي والذكاء الاصطناعي لتركيزه على الجوانب الأساسية والمهمة للبيانات.

3. تجنب المشاكل في التحليل

تحتوي البيانات على متغيرات متعددة ومتنوعة، ويساعد الترميز في اختيار السمات الأكثر أهمية وصلة للتركيز عليها.

4. تحسين التفاعلية

يحسن التفاعلية وسرعة استجابة النظام لاحتياجات المستخدمين، خاصة في النظم التفاعلية والتطبيقات الذكية.

1.2 ترميز الواحد الساخن (One-Hot Encoding)

يقوم One-Hot Encoding بتحويل البيانات النوعية التي تمثل فئات غير مرتبة (Nominal) إلى كود ثنائي من 0 و1، ويمثلها في عدة حقول جديدة؛ بحيث يمثل كل حقل جديد فئة واحدة من الفئات الأصلية، ويُوضع الرقم 1 في الحقل المقابل للفئة الفعلية و0 في بقية الحقول.

مثال المقرر: جدول الألوان (Color)
السمة الأصلية (Color) Red Blue Green
Green001
Blue010
Red100
Blue010
PYTHON • PANDAS GET_DUMMIES 
import pandas as pd

# تحويل حقل gender ذي الفئتين (M, F) إلى One-Hot Encoding
gender_encoded = pd.get_dummies(df['gender'])

# أو دمجه مباشرة مع إطار البيانات الأصلي
df_encoded = pd.get_dummies(df, columns=['gender'], dtype=int)
print(gender_encoded.head())

متى نفضل One-Hot Encoding؟

يُعد الخيار الأمثل للبيانات الاسمية (Nominal) مثل اللون أو الجنس أو المدينة؛ لأنه لا يعطي قيمة رقمية أكبر لفئة على حساب أخرى، مما يمنع نماذج التعلم الآلي من افتراض وجود أفضلية أو ترتيب رياضي بين الفئات.

1.3 ترميز التسميات (Label Encoding / Integer Encoding)

يُعرف أيضاً بـ Integer Encoding، ويقوم بترميز الفئات المختلفة في الحقل النوعي بقيم صحيحة متتابعة تبدأ من الصفر (0, 1, 2, ...). فمثلاً عند ترميز الألوان (Red, Green, Blue) يتم تحويلها إلى الأرقام 0, 1, 2 عبر الفئة LabelEncoder في مكتبة sklearn.preprocessing.

PYTHON • SKLEARN LABELENCODER & INVERSE_TRANSFORM 
from sklearn.preprocessing import LabelEncoder

# 1. إنشاء كائن بالمعاملات الافتراضية
le = LabelEncoder()

# 2. التعرف على الفئات وتوليد الرموز عبر fit_transform
encoded = le.fit_transform(df['department'])
print(encoded)
# الناتج: [1 0 0 2 1 2 1 0 2]

# 3. التحويل العكسي لإرجاع الرموز إلى قيمها الأصلية
original = le.inverse_transform([0, 1, 2])
print(original)
# الناتج: ['Finance' 'Operations' 'Sales']

آلية عمل fit_transform و inverse_transform

ترتب دالة LabelEncoder الفئات أبجدياً بشكل تلقائي (0 → Finance، 1 → Operations، 2 → Sales). وبعد استدعاء fit أو fit_transform، تحتفظ الأداة بخريطة التحويل مما يتيح استخدام inverse_transform() لاستعادة النصوص الأصلية من الرموز الرقمية.

1.4 الترميز الترتيبي (OrdinalEncoder)

يشبه LabelEncoder في تحويل الفئات إلى أعداد صحيحة، ولكنه يراعي الترتيب المنطقي (Order) عند ترميز الفئات الترتيبية عبر تمرير قائمة categories المحددة مسبقاً. ففي مثال درجات الموظفين من G0 إلى G4، تأخذ G0 القيمة 0، وتأخذ G1 القيمة 1، وهكذا حتى G4 = 4.

PYTHON • SKLEARN ORDINALENCODER 
from sklearn.preprocessing import OrdinalEncoder

# تحديد الترتيب الصريح للفئات عبر المعامل categories
grade_order = [['G0', 'G1', 'G2', 'G3', 'G4']]
oe = OrdinalEncoder(categories=grade_order)

# يتطلب OrdinalEncoder مصفوفة ثنائية الأبعاد df[['grade']]
df['grade_encoded'] = oe.fit_transform(df[['grade']])
التقنية نوع البيانات الأنسب مراعاة الترتيب الأعمدة الناتجة الأداة في بايثون
One-Hot Encoding نوعية اسمية (Nominal) لا تفرض ترتيباً عمود ثنائي (0/1) لكل فئة pd.get_dummies()
Label Encoding السمة الهدف أو الفئات التلقائية ترتيب أبجدي تلقائي عمود واحد (0, 1, 2...) LabelEncoder()
Ordinal Encoding نوعية ترتيبية (Ordinal) ترتيب مخصص عبر categories عمود واحد مرتب (0, 1, 2...) OrdinalEncoder()

UNIT 02 • FEATURE SCALING

الوحدة الثانية: تحجيم السمات

تغيير مقياس البيانات الرقمية لتوحيد نطاقها إلى مجال محدد مثل [0, 1] أو [-1, 1] أو متوسط صفر وانحراف معياري واحد، لمنع هيمنة السمات ذات القيم الكبيرة على حسابات النموذج.

2.1 مفهوم تحجيم السمات وأهميته

تحجيم السمات (Feature Scaling) هو عملية تغيير مقياس البيانات في مجموعة السمات بحيث يتم توحيد مقياسها أو تحويلها إلى نطاق محدد، مثل النطاق [0, 1] أو [-1, 1] أو تحويلها إلى متوسط يساوي صفراً وانحراف معياري يساوي واحداً.

1. تحسين أداء النموذج

خوارزميات مثل الانحدار الخطي (Linear Regression) والشبكات العصبية (Neural Networks) تعمل بكفاءة أعلى عندما تكون الميزات في نطاق متقارب دون تداخل من القيم الكبيرة جداً أو الصغيرة جداً في حساب دالة الهدف.

2. تسريع التدريب

توحيد مقياس البيانات يسرّع عملية تدريب النموذج، إذ يقلل من عدد الخطوات اللازمة لخوارزميات التحسين للوصول إلى الحل الأمثل.

3. تسهيل فهم البيانات

عندما تقع جميع الميزات في نطاق متساوٍ، يصبح من الأسهل فهم ومقارنة العلاقة بينها وبين المخرجات المستهدفة.

2.2 التحجيم القياسي (Standard Scaling / Z-Score Normalization)

تقوم هذه الطريقة بتوسيط البيانات حول الصفر وتحويل تشتتها باستخدام المتوسط الحسابي والانحراف المعياري، بحيث يصبح للسمة المحجمة متوسط 0 وانحراف معياري 1.

معادلة التوحيد القياسي (Z-Score)
$$Z_i = \frac{X_i - \mu}{\sigma}$$
Xᵢ = 723 (أول قيمة في مثال performance_score)
μ = 610.667 (المتوسط الحسابي للسمة)
σ = 222.194 (الانحراف المعياري للسمة)
التطبيق: (723 − 610.667) / 222.194 = 0.5056
PYTHON • SKLEARN STANDARDSCALER 
from sklearn.preprocessing import StandardScaler

scaler = StandardScaler()
df['performance_score_scaler'] = scaler.fit_transform(df[['performance_score']])

2.3 التحجيم الخطي (Min-Max Scaling)

تحول هذه الطريقة البيانات خطياً إلى نطاق جديد محدد من قبل المستخدم (وغالباً [0, 1]). ويُفضل استخدامها في الحالات التي يكون فيها الانحراف المعياري صغيراً جداً أو في حالة وجود قيمة متطرفة ذات معنى نرغب في الحفاظ عليها ضمن حدود النطاق.

معادلة التحجيم الخطي (Min-Max Scaling)
$$x_i' = \frac{x_i - Min_x}{Max_x - Min_x}(new\_max_x - new\_min_x) + new\_min_x$$
Minₓ = 53: أقل قيمة في البيانات الأصلية
Maxₓ = 901: أعلى قيمة في البيانات الأصلية
[new_minₓ, new_maxₓ] = [0, 1]: النطاق الجديد
التطبيق للقيمة 723: (723 − 53) / (901 − 53) × (1 − 0) + 0 = 0.7901
PYTHON • SKLEARN MINMAXSCALER 
from sklearn.preprocessing import MinMaxScaler

# الافتراضي هو النطاق [0, 1] ويمكن تخصيصه عبر feature_range
scaler = MinMaxScaler(feature_range=(0, 1))
df['performance_score_minmax'] = scaler.fit_transform(df[['performance_score']])

2.4 التحجيم المتين (Robust Scaling)

تعتمد هذه الطريقة على استخدام الربع الأول (Q₁) والربع الثالث (Q₃) والوسيط (الربع الثاني Q₂) في تحجيم البيانات؛ ولذلك يُفضل استخدامها عند وجود قيم متطرفة غير مرغوب بها لأن الأرباع لا تتأثر بالقيم الشاذة مثل المتوسط والحدين الأدنى والأقصى.

معادلة التحجيم المتين (Robust Scaling)
$$x_i' = \frac{x_i - Median_x}{Q_{3x} - Q_{1x}}$$
Q₁ = 556: قيمة الربع الأول
Q₂ (Median) = 674: قيمة الوسيط الحسابي / الربع الثاني
Q₃ = 711: قيمة الربع الثالث (IQR = 711 − 556 = 155)
التطبيق للقيمة 723: (723 − 674) / (711 − 556) = 49 / 155 = 0.3161

تنبيه امتحاني دقيق حول تسمية الوسيط في المقرر

يستخدم RobustScaler في البسط قيمة الوسيط (الربع الثاني = 674) رغم كتابة الرمز Meanₓ سهواً في إحدى شرائح العرض، وقد نصّ الشرح المرافق في المقرر بوضوح على أنها «قيمة الوسيط الحسابي أو الربع الثاني للبيانات» وقيمة الحساب الفعلي هي 674.

PYTHON • SKLEARN ROBUSTSCALER 
from sklearn.preprocessing import RobustScaler

scaler = RobustScaler()
df['performance_score_robust'] = scaler.fit_transform(df[['performance_score']])

UNIT 03 • FEATURE TRANSFORMATION

الوحدة الثالثة: تحويل السمات

تغيير شكل وتوزيع السمات الرقمية لتقليل أثر القيم المتطرفة، معالجة التوزيعات المائلة، تقطيع القيم المستمرة إلى فئات، واشتقاق سمات جديدة ذات دلالة تحليلية أقوى.

3.1 مفهوم تحويل السمات وعملياته الرئيسية

يؤدي تحويل السمات (Feature Transformation) إلى تعديل الميزات بحيث تكون بالشكل المطلوب للتحليل والنمذجة؛ كما يقلل من تأثير القيم المتطرفة، ويتعامل مع توزيعات البيانات المائلة (Skewed distributions)، ويجعل النموذج أكثر قوة. ويشمل ثلاث عمليات رئيسية:

1. التحويلات الحسابية

تطبيق عملية حسابية (مثل اللوغاريتم) على البيانات الرقمية لتحويلها إلى صورة أخرى أكثر اعتدالاً.

2. تقسيم السمات

تقسيم سمة واحدة إلى عدة سمات أو نطاقات بناءً على معايير محددة.

3. تجميع البيانات في فئات

استخدام سمة أو أكثر في تجميع البيانات معاً أو بناء سمة جديدة مشتقة.

3.2 تقطيع السمات إلى فئات (Discretization)

الغرض من Discretization هو تحويل السمات الرقمية المستمرة إلى مجموعة من الفئات أو النطاقات (مثل تحويل العمر إلى: أقل من 20، بين 20 و60، أكبر من 60). ومن أهم فوائدها تبسيط البيانات والمساعدة في تمثيلها بشكل أفضل.

في مثال المقرر على بيانات hoursPerWeek، أظهر رسم Histogram أن القيم موزعة على نطاق واسع مع تركز النسبة الأكبر عند 40 ساعة، فتم تقسيمها إلى ثلاث فئات: أقل من 40، يساوي 40، وأكثر من 40، ثم استخدام value_counts() لتمثيل التوزيع الجديد لأن السمة تحولت إلى سمة نوعية مكونة من عدة فئات.

نوع التقطيع آلية التقسيم الدالة / المثال في المقرر
Equal Width (متساوي العرض) تقسيم كامل النطاق [Min, Max] إلى عدد من النطاقات المتساوية في الطول الرياضي. pd.cut(series, bins=5)
Equal Frequency (متساوي التكرار) تقسيم كامل النطاق إلى عدد من النطاقات تحتوي على مجموع تكرارات متساوية تقريباً. تقسيم العمر إلى 5 نطاقات بتكرارات متقاربة (pd.qcut / cut كما ورد بالمقرر)
Ad Hoc (مخصص حسب الحاجة) يعتمد على اختيار محلل البيانات استناداً إلى خبرة مسبقة أو رسم مثل Histogram. تقسيم hoursPerWeek حول 40 ساعة
PYTHON • DISCRETIZATION (CUT & VALUE_COUNTS) 
import pandas as pd

# 1. تقطيع Ad hoc لساعات العمل الأسبوعية حول 40 ساعة
bins = [0, 39, 40, 100]
labels = ['Less than 40', 'Equal to 40', 'More than 40']
df['hours_cat'] = pd.cut(df['hoursPerWeek'], bins=bins, labels=labels)

# تمثيل توزيع الفئات الجديدة عبر value_counts()
print(df['hours_cat'].value_counts())

# 2. تقسيم العمر إلى 5 نطاقات (Equal width عبر cut، أو Equal frequency عبر qcut)
df['age_bins'] = pd.cut(df['age'], bins=5)
df['age_freq'] = pd.qcut(df['age'], q=5)

3.3 التحويل اللوغاريتمي (Log Transformation)

نستخدم Log Transformation عندما تشهد إحدى السمات نمواً أو انخفاضاً هائلاً عبر مجموعة كائنات البيانات؛ فعند رسم Box plot لهذه السمات تظهر نقاط كثيرة خارج شوكة الصندوق تشير ظاهرياً إلى قيم متطرفة، لكنها في الواقع قيم طبيعية ناتجة عن مصدر البيانات (وليست سجلات خاطئة).

في مثال المقرر على الناتج المحلي الإجمالي Gross Domestic Product (GDP) لعام 2020 في عدة دول، كان التوزيع شديد الالتواء قبل التحويل، وعند تطبيق دالة np.log() تقاربت القيم واختفى التشتت المفرط في الـ Box plot.

PYTHON • NUMPY LOG TRANSFORMATION 
import numpy as np

# تطبيق التحويل اللوغاريتمي الطبيعي على حقل GDP
df['GDP_log'] = np.log(df['GDP'])

3.4 بناء السمات (Attribute Construction)

تعني Attribute Construction إنشاء سمة (حقل) جديدة بناءً على مجموعة من الحقول أو السمات الموجودة بالفعل. ومن أبرز الأمثلة حساب مؤشر كتلة الجسم (BMI — Body Mass Index) اعتماداً على الوزن والطول بعد تهيئة بيانات الأشخاص.

معادلة اشتقاق مؤشر كتلة الجسم (BMI)
$$\text{BMI} = \frac{\text{Weight (kg)}}{(\text{Height (m)})^2}$$
PYTHON • ATTRIBUTE CONSTRUCTION (BMI) 
# إنشاء سمة BMI اعتماداً على الوزن (كجم) والطول (متر)
df['BMI'] = df['Weight'] / (df['Height'] ** 2)

# وإذا كان الطول مسجلاً بالسنتيمتر، نقسمه على 100 أولاً
df['BMI'] = df['Weight'] / ((df['Height_cm'] / 100) ** 2)
