    2. الاختزال (Downsampling): تقليل عينات فئة الأغلبية لتتوازن مع الأقلية.

    • تم إنشاء المسار باستخدام مكتبة Scikit-Learn، ويتكون من 3 خطوات متتالية: CountVectorizer() → TfidfTransformer() → ومصنف SGDClassifier (Stochastic Gradient Descent - تصنيف التدرج العشوائي) كموديل لتصنيف البيانات.

  • تقييم النموذج باستخدام مقياس F1 Score (ص 133):
    • تعريف F1 Score: مقياس يجمع ويعطي توازناً بين الدقة (Precision) والاستدعاء / الانتقالية (Recall)، وهو مفيد خاصة عندما تكون هناك عدة فئات وتكون البيانات غير متوازنة.
    • الدقة (Precision): تقيس النسبة المئوية للتصنيفات الصحيحة بين جميع التصنيفات التي قام بها النموذج.
    • الانتقالية / الاستدعاء (Recall): تقيس النسبة المئوية للعناصر الفعلية التي تم التنبؤ بها بشكل صحيح.
    • نطاق قيمة F1 Score: تتراوح قيمته بين 0 و 1، ويكون الأداء الأفضل عندما تكون القيمة أقرب إلى 1 (حقق النموذج في المشروع درجة ممتازة بلغت 0.9696 أي 0.96).
